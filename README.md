This is a simple program that demonstrates a connection for a Java JDBC with Maven and postgrSQL. 
1. You should create your won postgreSQL database to connect to. I created one named coffeeDB, I also added data to the table so we can confirm it works.
2. Use your DB credentials when writing the code.

<ol>
  <li>Maven</li>
